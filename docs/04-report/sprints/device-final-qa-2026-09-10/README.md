## 개선 수정 6건

1. **잠금 브러시 해금 다이얼로그 / 흔들어 지우기 다이얼로그 통일** — `DoodleController` 안에 남아 있던 옛 스타일(가운데 정렬 원형 아이콘 + TextButton)을 `AppConfirmDialog`로 교체. 리뉴얼 후 유일하게 다른 앱처럼 보이던 화면. 코드 150줄 감소.
2. **리치 피커 HEX 칸** — `0xFFF44336`(Dart 형식, 알파 접두어)이 좁은 칸에서 잘려 보였다. `copyFormat: numHexRRGGBB`로 `#F44336` 표시.
3. **토스트 테마화** — toastification 기본 `flatColored`(초록/빨강 굵은 테두리)가 종이 테마와 충돌. 표면색 카드 + 헤어라인 + 의미색 아이콘(성공=tertiary, 오류=error, 정보=primary)으로 통일.
4. **설정 초기화 다이얼로그** — 유일하게 `AlertDialog`였던 것을 `AppConfirmDialog`(파괴적 톤)로. 테스트는 `byType(AppConfirmDialog)`로 갱신.
5. **보관함 → 그리기 복귀 시 DrawPage 이중 적재 → 캔버스 빈 화면 (버그, 출시 차단급)** — 그리기 화면의 "내 작품"으로 들어와 작품을 지우거나 연 뒤 그리기로 돌아갈 때 DrawPage 위에 DrawPage가 한 장 더 올라갔다. 두 장이 같은 `canvasKey`(GlobalKey)를 쓰므로 위 장이 닫히면 **아래 장의 캔버스 서브트리가 빈 화면**으로 남는다(툴바만 보이고 그리기 불가, 도화지 색을 바꾸면 그제야 다시 그려짐). 원인은 `Get.previousRoute == Routes.DRAW` 판별 — CLAUDE.md에 이미 기록된 대로 `previousRoute`는 다이얼로그/시트를 한 번 띄우면 오염된다(삭제 확인 다이얼로그 후 `_openArtwork`/`_goToDraw` 모두 실패). DrawPage가 보관함을 열 때 `arguments: GalleryPage.fromDrawArguments`를 넘기고 보관함은 `Get.arguments`로만 판별하도록 교체. 회귀 테스트: 다이얼로그를 한 번 띄운 뒤 "Start Drawing" → `DrawPage` 정확히 1개.
6. **종료 시트 프리미엄 배너** — 안내만 있고 누를 수 없었다. 탭하면 시트를 닫고 프리미엄으로 이동 + chevron 표시.

## 관찰만 (수정 안 함)

- 도화지 색은 "지우기" 후에도 유지된다. 배경색은 그림이 아니라 환경 설정으로 취급하는 현재 설계가 맞다고 판단.
- 홈의 "이어 그리기 / 새로 시작" 다이얼로그는 홈 진입 시 항상 캔버스를 비우는 현재 흐름에서는 사실상 도달 불가(QA 라우트 지정 시만). 삭제하지 않고 방어 코드로 둠.
- `W/Ads: Invoke Firebase method getInstance error.` — google_mobile_ads가 Firebase Analytics 부재 시 내는 경고. 기능 영향 없음.
- 검정 도화지에서 검정 브러시는 보이지 않는다(당연). 도화지 색 변경 시 브러시 색 자동 대비는 과한 기능으로 보아 보류.
