## Google Play 스크린샷 가이드

### 스크린샷 개요
- 짧은 제목 + 바로 이해되는 기능 문구로 구성
- 1장: 홈 화면과 빠른 시작
- 2장: 풀스크린 드로잉 캔버스
- 3장: 브러시와 색상 팔레트
- 4장: 사진 위 드로잉
- 5장: 작품 보관함과 저장
- 6장: 설정 / 후원형 Premium

---

## 스크린샷 구성 (6장)

> **규칙**: 제목과 부제목은 모바일 화면 가독성을 위해 **최대 2~3단어**를 넘지 않도록 간결하게 구성합니다.

### 1장: 홈 화면과 빠른 시작
- **기본안**:
  - **제목(KO)**: **간단한 그림판**
  - **부제목(KO)**: **열면 바로 그리기**
  - **Title(EN)**: **Simple Drawing Pad**
  - **Subtitle(EN)**: **Open and draw**
- **후보군 (KO / EN)**:
  - **후보 1 (행동·직관)**: 쉬운 그림판 / 켜고 바로 그리기 (Easy Drawing Pad / Tap and draw)
  - **후보 2 (감성·종이)**: 가벼운 스케치북 / 새 종이처럼 (Light Sketchpad / Like fresh paper)
  - **후보 3 (기능·ASO)**: 간단 그림판 / 무료 낙서 앱 (Simple Paint App / Free doodle app)

> 1장은 첫인상이므로 기능 나열 대신 **"이건 간단한 그림판이다"** 한 가지만 전달한다.
> 드로잉·캔버스·툴 같은 앱 용어보다 그림판·낙서·그리기처럼 누구나 아는 말을 쓴다.

**캡처 화면**: 홈 화면에서 최근 작품 히어로와 `Start Drawing` / `My Artworks` 진입이 보이는 상태
- **포함 요소**:
  - 최근 작품 3장을 겹친 종이 묶음 히어로
  - 홈 주요 CTA(`Start Drawing`)와 작품 보관함 진입(`My Artworks`)
  - 설정 / 프리미엄 진입 행
  - 무료 버전이면 하단 배너 광고 영역
  - 앱이 단순하다는 인상을 주도록 요소 최소화

---

### 2장: 풀스크린 드로잉 캔버스
- **기본안**:
  - **제목(KO)**: **넓은 캔버스**
  - **부제목(KO)**: **방해 없는 화면**
  - **Title(EN)**: **Full Canvas**
  - **Subtitle(EN)**: **Draw with focus**
- **후보군 (KO / EN)**:
  - **후보 1 (행동·직관)**: 화면 가득 / 거침없이 그리기 (Edge to Edge / Draw freely)
  - **후보 2 (감성·종이)**: 종이처럼 넓게 / 여백 가득 (Spacious Canvas / Room to sketch)
  - **후보 3 (기능·ASO)**: 풀스크린 드로잉 / 넓은 작업 공간 (Fullscreen Drawing / More open space)

**캡처 화면**: 실제 선이 그려진 드로잉 화면
- **포함 요소**:
  - 넓은 종이색 캔버스에 실제 그림이 그려져 있는 상태
  - 상단 툴바의 저장 / 공유 / 실행 취소 / 다시 실행 / 내 작품 / 더보기
  - 하단 3단 툴바(브러시 퀵 · 굵기 슬라이더 · 색상 퀵)
  - 광고나 다이얼로그가 화면을 가리지 않는 상태

---

### 3장: 브러시와 색상 팔레트
- **기본안**:
  - **제목(KO)**: **10종 브러시**
  - **부제목(KO)**: **질감까지 다르게**
  - **Title(EN)**: **10 Brushes**
  - **Subtitle(EN)**: **Real brush textures**
- **후보군 (KO / EN)**:
  - **후보 1 (행동·직관)**: 다양한 브러시 / 살아있는 필감 (Diverse Brushes / Feel the strokes)
  - **후보 2 (감성·종이)**: 펜부터 수채화까지 / 풍부한 질감 (Pen to Watercolor / Natural textures)
  - **후보 3 (기능·ASO)**: 브러시 & 색상 / 16색 커스텀 팔레트 (Brushes & Colors / 16 color palette)

**캡처 화면**: 브러시 선택 시트 또는 색상 선택 시트가 열린 화면
- **포함 요소**:
  - 10종 브러시 셀렉터(펜, 연필, 마커, 붓, 형광펜, 만년필, 크레파스, 수채화, 에어브러시, 지우개)
  - 16색 팔레트 + 커스텀 컬러 피커(HEX 입력)
  - 브러시 크기 슬라이더와 굵기 미리보기
  - 수채화 / 에어브러시의 잠금 표시(보상형 광고 또는 Premium으로 해금)

- **기본안**:
  - **제목(KO)**: **사진 위 드로잉**

**캡처 화면**: 갤러리 사진을 참조로 깔고 그 위에 선을 그린 상태
- **포함 요소**:
  - 배경에 깔린 사진과 그 위의 실제 드로잉
  - 사진 불러오기 진입(더보기 시트)
  - 참조 사진이 작품과 함께 보존된다는 맥락
  - 사진과 선이 구분되도록 대비가 좋은 예시 이미지 사용

## 캡처 팁

### 일반 가이드라인
- **해상도**: 최소 1080x1920
- **형식**: PNG 권장
- **비율**: 9:16 우선
- **기기**: 실제 Android 디바이스 캡처 권장
- **테마**: 밝은 테마 우선, 색상 팔레트와 종이색 캔버스가 잘 보이도록 촬영
- **상태**: 빈 화면 대신 실제 작품이 그려진 상태로 촬영하고, 광고 배너는 비행기 모드로 숨긴다

> 시드 도구: `--dart-define=DOODLE_PAD_QA_SEED_ARTWORKS=true` 로 실행하면 보관함에 프로그램 생성 작품 8점이 심어진다.
> 시드 코드 변경 후에는 `am force-stop` 뒤 재실행해야 반영된다.

### 강조할 요소
- 앱을 열고 바로 그릴 수 있는 흐름
- 10종 브러시와 16색 팔레트 + 커스텀 컬러
- Undo / Redo로 실험하기 쉬운 구조
- 갤러리 사진 위에 덧그리는 사진 드로잉
- PNG·JPEG 기기 갤러리 저장, 앱 내 작품 보관함, Android 공유
- 후원형 Premium의 3개 옵션과 광고 제거

### 스크린샷 배치 순서
1. 홈 화면과 빠른 시작
2. 풀스크린 드로잉 캔버스
3. 브러시와 색상 팔레트
4. 사진 위 드로잉
5. 작품 보관함과 저장
6. 설정 / 후원형 Premium

### 핵심 가치 제안
- 앱 실행 후 바로 그리기
- 10종 브러시 제공 (펜·연필·마커·붓·형광펜·만년필·크레파스·수채화·에어브러시·지우개)
- 16색 팔레트 + 커스텀 컬러와 브러시 크기 조절
- 갤러리 사진 위 드로잉과 참조 사진 보존
- 기기 갤러리 저장(PNG·JPEG), 앱 내 작품 보관함, 다시 열어 편집, 공유까지 한 흐름
- 1회 후원으로 광고 제거와 Premium 브러시 접근

### 차별화 요소
- 드로잉에 필요한 기능만 간결하게 제공
- perfect_freehand 기반으로 긋는 속도에 따라 굵기가 변하는 선
- 저장한 작품을 보관함에서 다시 열어 이어 편집 가능 (참조 사진도 함께 보존)
- 흔들어 지우기 같은 가벼운 조작
- 보상형 광고 또는 Premium으로 특수 브러시 접근 가능
- 11개 언어 지원과 라이트/다크 테마

### 경쟁 앱 대비 장점
- 튜토리얼이나 계정 없이 실행 즉시 그릴 수 있음
- 전문가용 레이어 도구 없이도 질감이 다른 브러시 10종을 제공
- 그림과 참조 사진을 함께 보관해 이어 그리기가 끊기지 않음
- 저장 포맷(PNG·JPEG)과 해상도(1x·2x·3x)를 저장 시점에 직접 선택
- 작품이 기기 로컬에만 저장되어 계정·클라우드 업로드가 필요 없음
- 구독이 아닌 1회 후원으로 광고를 영구 제거
